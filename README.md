# Personal Expense Tracker

A simple web-based expense tracking application built using Python, Flask, HTML, CSS, and SQLite.

## Features
- Add daily expenses
- View all expenses
- Calculate total expenses
- Delete expenses
- Store expense records using SQLite
- Simple and responsive user interface

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run

1. Install Flask:
   `pip install Flask`
2. Open the project folder in VS Code.
3. Run:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.
